# Repo2Resume

Inspect public GitHub repositories, extract technical architecture and dependencies, and generate quantified Google XYZ formula achievements for your resume.

## Features

- **Google XYZ Formula**: Quantifies achievements (*"Accomplished [X] as measured by [Y], by doing [Z]"*).
- **Job Description Keyword Matcher**: Auto-extracts required technical skills and scores repository relevance.
- **ATS Scanner Formats**: Instant export to Markdown, LaTeX, and JSON Resume formats.
- **Privacy First**: API keys are stored strictly in local browser storage.

## Local Setup

```bash
# Clone the repository
git clone https://github.com/imsayanpaul/Repo2Resume.git

# Install dependencies
npm install

# Start local dev server
npm run dev
```
